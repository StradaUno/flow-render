# flow-render

Runner der Meme Fabrik (Testversion). Führt KI- und Render-Aufträge aus, die er von der Fabrik abholt, und meldet die Ergebnisse zurück.

Dieses Repo enthält **keine Daten, keine Prompts und keine Geheimnisse**. Schlüssel liegen ausschließlich als GitHub-Secrets vor; die Logs zeigen nur Auftrags-IDs.
